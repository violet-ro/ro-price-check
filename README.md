# NiktoutRO vending ledger

Public Page: [violet-ro.github.io/ro-price-check/](https://violet-ro.github.io/ro-price-check/)

A price tracker for [classiccp.niktoutro.com/vending](https://classiccp.niktoutro.com/vending/). A snapshot of each vendor's listing is used and this basic page lets you search
for an item by partial name and see a scatter plot of what it's sold for, by shop, over time.

Because snapshots are gathered manually, the data may be outdated. Please reach Violet on discord to request an update!
